# Changelog

## 0.2.0 — Local AI Director

- Prompt em linguagem natural para criação de filme.
- Planejador narrativo JSON com Ollama/llama.cpp e fallback local.
- Perfil automático de CPU, RAM, GPU e VRAM.
- Recomendação adaptativa de Qwen 3.5 / Qwen3-Coder.
- Download de modelo Ollama pela interface.
- Setup Windows via winget.
- Gramática procedural genérica para cenas e entidades.
- Modos DSL, híbrido e código total.
- Validador de JavaScript gerado por IA.
- Presets YouTube 720p/1080p/2K/4K, Shorts, Reels, Instagram quadrado e TikTok.
- Áudio procedural 48 kHz estéreo orientado pelo storyboard.
- Upload e mux de áudio do usuário.
- Filme mudo.
- Seleção NVENC somente quando GPU NVIDIA realmente está presente; libx264 como fallback.
- Storyboard visual na interface.
- Diagnóstico de hardware/IA na interface.
