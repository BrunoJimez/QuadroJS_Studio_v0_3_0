# Changelog

## 0.1.0

- Interface local para Windows/Linux/macOS via Node.js.
- Preview Canvas 2D com play, pause, scrub e timeline.
- Controle de resolução, FPS, duração, seed e paleta.
- Seis cenas procedurais demonstrativas sem assets de imagem/vídeo.
- Modo de script JavaScript personalizado.
- PRNG determinístico, ruído, hachura, halftone, papel, campo hexagonal e primitivas orgânicas.
- Exportação quadro a quadro por Chromium + FFmpeg H.264.
- Fallback de gravação WebM no navegador via `canvas.captureStream()` e `MediaRecorder`.
- Auto-detecção de Chrome/Edge/Chromium e FFmpeg.
